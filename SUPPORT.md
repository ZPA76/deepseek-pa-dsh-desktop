# Support

- DPA desktop, cluster, theme, GitHub extension center: open an Issue in this repository.
- Design proposals and usage questions: use GitHub Discussions.
- DSH runtime, plugin loader or upstream web UI: use the official DSH repository and Discussions: https://github.com/deepseek-ai/deepseek-harness/discussions

Please include versions and a redacted reproduction. Never post API keys, OAuth tokens, `.credentials.yaml`, private project files or full local logs.
