# Public export manifest

This folder is a sanitized GitHub-ready export of the DPA desktop source at version 0.5.1.

Included: application source, tests, build scripts, public documentation, community files and CI.

Intentionally excluded: `node_modules`, `dist`, `dist-staging`, `.dpa-backups`, `app-src` generated mirror, DSH checkout, DSH_HOME, project/employee data, logs, caches, credentials and private conversation records.

Before pushing, run the search in `GITHUB_UPLOAD_GUIDE.md` and review the diff manually. Replace the copyright holder in `LICENSE` if your preferred legal name or organization differs.
