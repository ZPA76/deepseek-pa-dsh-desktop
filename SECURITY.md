# Security Policy

## Supported versions

Only the latest published developer-preview release receives security fixes. DPA depends on the rapidly changing DSH preview, so upgrade both components when a security notice affects the runtime.

## Reporting a vulnerability

Do not open a public Issue containing credentials, private data or an exploit. Use GitHub's private vulnerability reporting if enabled for the repository, or contact the maintainer privately through the repository owner's public profile.

Include the affected version, a minimal reproduction, impact and a safe way to test the fix. Revoke any exposed API key or OAuth token immediately.
